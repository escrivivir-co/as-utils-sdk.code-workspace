**Endpoint**: `POST http://localhost:4001/ai`

{

  "input": "¿Cuál es el estado de mi servidor?",

## 🔍 Complete Integration Example

```javascript

// Client implementation for MCP conversations

class MCPConversationClient {

  constructor(baseUrl = 'http://localhost:4001') {

    this.baseUrl = baseUrl;

  }

  async chatWithPreset(message, presetName) {

    const payload = {

      input: message,

      node_llama_cpp_MCP_functions: true,

      presetName: presetName,

      mcpServerUrl: "http://localhost:3003",

      usePresetTools: true

    };

    try {

      const response = await fetch(`${this.baseUrl}/ai`, {

        method: 'POST',

        headers: { 'Content-Type': 'application/json' },

        body: JSON.stringify(payload)

      });

      if (!response.ok) {

        throw new Error(`HTTP ${response.status}: ${response.statusText}`);

      }

      const result = await response.json();

      return result;

    } catch (error) {

      console.error('❌ MCP conversation failed:', error.message);

      throw error;

    }

  }

}

// Usage example

const client = new MCPConversationClient();

const response = await client.chatWithPreset(

  "¿Cuál es el estado del sistema?", 

  "BasicServerStatus"

);

console.log('Response:', response.answer);

```

## 🎯 Key Parameters Explained

- **`node_llama_cpp_MCP_functions: true`** - Activates native MCP support

- **`presetName`** - Specifies which MCP preset to use

- **`mcpServerUrl`** - MCP server endpoint (default: `http://localhost:3003`)

- **`usePresetTools: true`** - Forces use of preset-specific tools

- **`functionSets`** - Optional array to limit function groups

- **`input`** - Your conversation message/query

## 🔗 Service Integration Chain

The complete flow is:

```

Your Request → SLMo042 (4001) → MCPGaia (3003) → MCP Tools/Resources

```

Make sure all services are running:

1\. **MCPGaia**: Port 3003 (MCP server with tools/resources)

2\. **SLMo042**: Port 4001 (AI inference + MCP proxy)

3\. **Zeus**: Port 3012 (Web interface, optional)
